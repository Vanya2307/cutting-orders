## За проекта

Клиентите избират материали, въвеждат детайли с размери и кантове, избират допълнителни обработки и прикачват чертежи. Преди изпращане прегледват цялата поръчка. При изпращане поръчката получава номер, заключва се за редакция и се създава Excel файл.

Проектът е основан на практическа работа в мебелен цех. Excel файлът следва табличния формат, използван в цеха. Сайтът е на български език.

> Целта е да се намали ръчното преписване на размери от хартиени бланки и поръчките да се проверяват и подготвят по-лесно за производство.

## Функционалности

**Каталог**

- Материали с тип, производител, декор, дебелина, размер на плочата и фладер.
- Услуги с изискване за чертеж: не е нужен, препоръчителен или задължителен.
- Страници за създаване, преглед, редакция и изтриване на материали и услуги.
- Търсене по код или име на декора от навигацията.
- Търсене с една или няколко думи, с поддръжка на главни и малки букви на кирилица.
- Защита срещу изтриване на материали и услуги, използвани в поръчки.

**Поръчки**

- Поръчката започва с данните за контакт на клиента.
- Телефонните номера се записват във формат `+359` и се използват за откриване на съществуващ клиент.
- Материалите се избират от списък с филтри по тип, производител и декор.
- Избраният материал е заключен във формата за детайл.
- Детайлите съдържат размери, брой, посока на фладера, четири канта, обработки, евросглобки и бележки.
- Детайлите се добавят, редактират и изтриват, докато поръчката е чернова.
- Прегледът на поръчката групира детайлите по материал в компактна таблица.
- Могат да се прикачат няколко чертежа: PDF, JPG и PNG, до 5 MB на файл.

**Производствени проверки**

- Детайлите трябва да се побират в полезния размер на плочата след окрайчване.
- Проверката на размера отчита избраната посока на фладера.
- При материал с фладер се изисква посока или изричен избор „Без значение“.
- Стандартна евросглобка е възможна само при плот, с ширина на детайла 600 мм.

**Изпращане**

- Страница за потвърждение показва поръчката преди изпращане.
- Клиентът потвърждава, че е проверил размерите, кантовете и обработките.
- Изпращането е спряно, ако поръчката няма детайли или липсва задължителен чертеж.
- Показва се предупреждение, когато чертеж е препоръчителен, но не е прикачен.
- Изпратените поръчки получават номер, например `A-2026-0001`, и стават само за преглед.
- Създава се Excel файл, който се изтегля от страницата на поръчката.

**Други страници**

- Начална страница с актуален брой материали и услуги.
- „Моите поръчки“ с черновите и изпратените поръчки от браузър сесията.
- Собствена страница 404.

## Поверителност и достъп

- Клиентите сами въвеждат данните си за контакт. Няма публичен списък с клиенти.
- Достъпът до поръчка е ограничен до браузър сесията, в която е създадена.
- Въвеждането на съществуващ телефонен номер не дава достъп до предишни поръчки.
- Страниците на поръчките, чертежите и Excel файловете се проверяват спрямо сесията.
- Всеки, който ползва същия браузър профил и сесия, има достъп до тези поръчки.
- Изтриването на бисквитките или изтичането на сесията може да премахне достъпа. Поръчките остават в базата данни.
- Изпратените поръчки са само за преглед, като ограниченията се проверяват във views.

Регистрация и вход не са част от този курсов проект. В тази версия каталогът се редактира без вход, тъй като версията е предназначена за локална демонстрация. Потребителски профили и управление само от служители са планирани да се направят.

При изпращане поръчката се записва и се създава нейният Excel файл. Изпращането по имейл е планирано за следваща версия.

## Технологии

- Python 3.12
- Django 6.1.2
- SQLite
- openpyxl за Excel файла
- Bootstrap 5 и собствен CSS

## Структура

- `catalog/`  
  Материали и услуги: модели, форми, филтриране и CRUD views.
- `orders/`  
  Клиенти, поръчки, детайли и чертежи. Достъп чрез сесия, изпращане и изтегляне.
- `orders/templatetags/order_extras.py`  
  Собствен филтър `edge` за показване на дебелината на канта.
- `production/excel.py`  
  Създаване на Excel файла с openpyxl.
- `templates/`  
  Основна, начална и 404 страница, и templates на страниците, групирани по приложение (`catalog/`, `orders/`).
- `templates/includes/`  
  Обща навигация и footer.
- `static/css/style.css`  
  Стиловете на сайта, с цветове, зададени чрез CSS променливи.
- `docs/`  
  Изображения за този README.

## Инсталиране

Нужни са Python 3.12 и pip. Хранилището се клонира с Git или се изтегля и разархивира като ZIP.

1. Клониране на хранилището:

   ```bash
   git clone https://github.com/Vanya2307/cutting-orders.git
   cd cutting-orders
   ```

2. Създаване на виртуална среда:

   ```bash
   python -m venv .venv
   ```

3. Активиране с командата за съответната система.

   **Linux / macOS / WSL:**

   ```bash
   source .venv/bin/activate
   ```

   **Windows PowerShell:**

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

   **Windows Command Prompt:**

   ```bat
   .venv\Scripts\activate.bat
   ```

4. Инсталиране на зависимостите:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Прилагане на миграциите:

   ```bash
   python manage.py migrate
   ```

6. Стартиране на сървъра:

   ```bash
   python manage.py runserver
   ```

7. Отваряне на <http://127.0.0.1:8000/>.

Не са нужни environment променливи или данни за достъп до база данни. SQLite създава локалната база при прилагане на миграциите. Не са нужни предварително въведени данни.

Качените чертежи и създадените Excel файлове се пазят в `media/`. Тези файлове и локалната база не са част от хранилището.

### Първо използване

1. Отворете **Материали** и добавете материал.
2. Отворете **Услуги** и добавете услуга с изискване за чертеж.
3. Изберете **Нова поръчка** и въведете данните за контакт.
4. Изберете материал, добавете детайли и прикачете чертежи при нужда.
5. Прегледайте поръчката, потвърдете данните и я изпратете.
6. Изтеглете Excel файла.

**Моите поръчки** връща към черновите и изпратените поръчки, докато браузър сесията е активна.

Всички обекти се създават през навигацията на сайта. Django admin и директна редакция на базата не са нужни.

## Excel файл

Файлът следва работната таблица, използвана в цеха.

| Колона | Съдържание |
| --- | --- |
| A | Пореден номер, започва от 1 за всеки материал |
| B | Материал |
| C | Посока на фладера: `L`, `W` или празно |
| D | Наименование |
| E, F | Дължина и ширина в мм |
| G | Брой |
| H-K | Кантове: L горе, L долу, W ляво, W дясно |
| L | Друго |
| M | Дебелина на материала в мм |
| N | Номер на поръчката и име за етикетите |
| O | Обработки и евросглобки |

Ред 1 съдържа номера на поръчката, името, телефона и датата на изпращане. Редове 2-3 съдържат заглавията. Два празни реда разделят групите материали.

Размерите, бройките, кантовете и дебелините са числа. Липсващ кант е празна клетка. Дългите имена на материали и бележки се пренасят в клетката.
