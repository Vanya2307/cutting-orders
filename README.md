# Cutting Orders
---
Django web app for furniture panel cutting and edge-banding orders, with Excel export.

**Author:** Vanya Videva  
**Course:** Python Web - Django Basics, SoftUni  
**Date:** September-October 2026


## Concept
 
Clients submit cutting orders through the site: a material is chosen from the catalog, part dimensions and quantities are entered, and grain direction, edge banding and services are specified for each part, drawings are attached if needed. When the order is sent, an Excel file is generated for the cutting machines.
